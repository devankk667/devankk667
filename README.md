### 🌟 Featured Projects

#### 🔥 [namyadam](https://github.com/devankk667/namyadam): AI Industrial Thermal Anomaly & Fire Monitoring

A geospatial decision-support platform that detects and classifies industrial fires, flare stacks, wildfires, and agricultural burns from NASA FIRMS thermal data plus OpenStreetMap context.

- 🧪 **Leakage-safe validation:** spatial `GroupKFold` so geographically adjacent clusters never straddle the train/test split
- 🤖 **Model bake-off:** Logistic Regression vs Random Forest vs XGBoost vs PyTorch NN
- 🚨 **Early-warning engine:** rule-based alerts for high-FRP outbursts and persistent flare anomalies
- 🗺️ **React + Leaflet dashboard** with an interactive prediction studio, backed by a **FastAPI** service
- 📴 Ships with an offline demo mode (simulated data around real industrial hubs)

`Python` `FastAPI` `PyTorch` `XGBoost` `React` `Leaflet` `Docker`
